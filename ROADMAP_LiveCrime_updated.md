# LiveCrime — ROADMAP

## Статус проекта

**Текущая стадия:** рабочий локальный прототип, готовый к первой реальной проверке Telegram-публикации.

Основной режим публикации:

```python
POST_MODE = "single"
```

То есть:

> **1 новость = 1 Telegram-пост**

Главное ограничение проекта:

> LiveCrime должен работать на бесплатных технологиях, без платных AI API и без обязательных платных новостных API.

---

# Текущий конвейер

```text
RSS-источники
    ↓
сбор новостей
    ↓
нормализация данных
    ↓
фильтр по дате
    ↓
мягкий тематический фильтр
    ↓
рейтинг интересности
    ↓
дедупликация
    ↓
история / DRY_RUN
    ↓
selected_news
    ↓
загрузка HTML статьи
    ↓
извлечение и очистка article_text
    ↓
формирование отдельного поста
    ↓
Telegram Bot API
```

## v1.0

Стабильный бесплатный LiveCrime Autoposter, который автоматически:

1. собирает новости;
2. фильтрует и ранжирует их;
3. удаляет дубли;
4. извлекает полный текст;
5. формирует отдельные Telegram-посты;
6. публикует их;
7. не повторяет уже опубликованные материалы;
8. устойчиво работает по расписанию.

# Ближайший шаг

Сейчас разработку ядра можно временно остановить.

Ждём данные Telegram-бота и канала.

После получения:

1. заполнить `.env`;
2. установить `MAX_NEWS_PER_RUN = 1`;
3. временно переключить `DRY_RUN = False`;
4. выполнить одну реальную публикацию;
5. проверить пост в канале;
6. проверить `published.json`;
7. вернуть безопасные настройки для дальнейшей разработки;
8. после успешного теста перейти к расписанию и дополнительным источникам.
