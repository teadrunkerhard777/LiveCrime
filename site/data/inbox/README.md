# Очередь кандидатов

Сюда независимый генератор сайта помещает только новые записи из подтверждённой
истории LiveCrime. Для криминального пилота кандидат должен быть опубликован не
более семи суток назад и прямо сообщать минимум о двух жертвах убийства.
JSON-файл в этой папке ещё не является страницей сайта и не попадает в
поисковую индексацию.

Каждый кандидат получает `quality_gate.publishable: false`. Для превращения в
карточку нужны отдельная проверка источника, самостоятельное краткое изложение,
дата и место события, юридический статус и настоящие ссылки каналов.

Генератор не меняет `storage/published.json`, не вызывает Telegram и не
обращается к сайтам СМИ.

JSON-кандидаты исключены из Git. В репозитории сохраняется только этот файл с
правилами, а реальные записи остаются локальными до редакционной проверки.
