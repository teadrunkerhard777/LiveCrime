# Редакционная проверка

Рабочие JSON-заметки о реальных событиях хранятся в этой папке только локально
и исключены из Git. Они могут содержать неподтверждённые сведения и не должны
попадать ни в репозиторий, ни в сборку сайта.

Публичный Markdown-материал создаётся отдельно лишь после проверки источников,
заполнения обязательных фактов и явного прохождения контроля качества.
