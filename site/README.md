# «По факту» — сайт медиахаба

Отдельный статический сайт будущего тематического медиахаба «По факту». Первый
пилотный раздел — «Криминал». После проверки процесса к общей системе можно
добавить Roblox, кошек, MMA, автомобили и звёзд.

Сайт не публикует сообщения в Telegram или MAX и не изменяет состояние
автопостеров. Отдельные импортёры читают публичные веб-ленты каналов, сохраняют
текст, изображение, дату и прямую ссылку на конкретный Telegram-пост.

## Основные страницы

- `/` — главная страница хаба;
- `/crime/` — лента публичных постов `@truecrime_news`;
- `/crime/<event-id>/` — постоянная карточка события;
- `/roblox/` — прямая лента фото-постов Roblox Hub;
- `/about/` — понятное описание проекта для читателя.

## Локальный запуск

```bash
npm install
npm run dev
```

## Лента криминальных публикаций

Workflow `Crime Site Feed` в 08:00, 14:00 и 20:00 по Екатеринбургу читает
публичную веб-ленту `@truecrime_news`. Он переносит фото-посты как есть, защищает
ленту от дублей по ID сообщения и сразу обновляет GitHub Pages. В каждой записи
есть ссылка на конкретный Telegram-пост и на канал в MAX.

Импорт выполняется без Telegram-токена и не читает и не изменяет
`storage/published.json`. Старый генератор постоянных карточек сохранён только
для ручного запуска и больше не работает по расписанию.

Сайт не создаёт автоматические страницы городов, тегов и ключевых слов. Новый
публичный маршрут добавляется только вместе с самостоятельным полезным
содержанием; это правило проверяется тестами при каждой публикации.

Проверка типов и production-сборка:

```bash
npm run build
```

## Временный адрес GitHub Pages

Для этого репозитория production-сборка использует временный адрес:

```text
https://teadrunkerhard777.github.io/LiveCrime/
```

Локально такую же структуру адресов можно проверить командой:

```bash
SITE_URL=https://teadrunkerhard777.github.io \
BASE_PATH=/LiveCrime npm run build
```

Отдельный `.github/workflows/site.yml` собирает только папку `site/`. Он не
запускает автопостер, не получает Telegram secrets и не изменяет
`storage/published.json`.

## Лента Roblox

Workflow `Roblox Site Feed` один раз вечером, в 20:00 по Екатеринбургу, читает
публичную веб-ленту `@RobloxHubRU`. Он переносит только сообщения, в которых
одновременно есть текст и фотография, сохраняет ID Telegram-сообщения для
защиты от дублей и сразу обновляет GitHub Pages. В каждой записи есть ссылка на
конкретный Telegram-пост и на канал в MAX. Telegram-токен не используется, а
отдельный Roblox-автопостер не изменяется.

Чтобы выполнить первое развёртывание, после отправки файлов в GitHub необходимо
один раз выбрать **GitHub Actions** как источник публикации в настройках Pages
репозитория. Подключение собственного домена позднее не потребует переписывать
контент.

Продуктовые решения зафиксированы в [PRODUCT.md](./PRODUCT.md), а подробный план
находится в [ROADMAP.md](./ROADMAP.md).
