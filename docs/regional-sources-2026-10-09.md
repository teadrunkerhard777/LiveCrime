## Извлечение текста

Проверены по две реальные статьи каждого нового источника (28 статей).
На новых HTML-сайтах используется `articleContent_* / uiArticleBlockText_*`
внутри article с h1: фотокредиты, погода, навигация и внешний footer исключены.
Для этих доменов явно выставляется UTF-8, иначе requests без HTTP charset
возвращает испорченную кириллицу. На НГС24 внутри body подтверждены служебная
подписка и просьбы прислать сведения — они исключены только для новой группы.
Редакционные ссылки и содержательные фоновые абзацы не удаляются глобально.

Северные контейнеры:

- БНК: `.b-news-single .cnt.daGallery`;
- Комиинформ: `.news-view [itemprop="articleBody"]`;
- СеверПост: первый div после hr, следующего за прямым h1 в `.c-post-block`;
- НАО24: `article.fullstory .box_in > .text`.

При отсутствии надёжного контейнера возвращается пустой текст для штатного
description fallback, а не все абзацы страницы. Из одного HTML по-прежнему
извлекаются текст и image URL; изображения не скачиваются для диагностики.
В проверенных 28 статьях найден непустой body и image URL. Доступность URL
из Telegram и успешность sendPhoto не проверялись.

## Известные ограничения прежних источников

- OmskMedia RSS происшествий: HTTP 404 с HTML вместо XML. HTML-рубрика
  доступна, но прямой ответ показывает старые карточки. Первая проверенная
  статья имеет JSON-LD datePublished `2026-06-10T09:47:00+00:00`.
  Переводить источник на этот HTML вслепую нельзя; добавлена альтернатива НГС55.
- VN.ru: повторные timeout. Добавлена альтернатива НГС для Новосибирска,
  без обхода защиты и без изменения адаптера VN.
- Обычный полный DRY_RUN пришлось остановить на TLS-соединении к старому
  RSS MK.ru: feedparser URL-fetch не задаёт timeout. Для повторной диагностики
  временный `socket.setdefaulttimeout(20)` устанавливался только во внешнем
  запускающем процессе, не в коде проекта. Это отдельная задача устойчивости RSS.

Все проверки выполняются без реальной публикации и без ручного изменения
`storage/published.json`. Для локальных RSS-диагностик необходимо сначала
вызвать штатный `configure_ssl()`, как это делает main.py. TLS-проверка не отключается.
