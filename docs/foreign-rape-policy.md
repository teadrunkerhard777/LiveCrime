# Зарубежные изнасилования: редакционное ограничение

Зарубежное изнасилование само по себе больше не проходит. Исключения:
явное групповое изнасилование или связанное убийство той же жертвы.
Российские события, зарубежные убийства и остальные hard topics не менялись.

Проверка находится в filter_by_event_policy после загрузки статьи и до
дедупликации/history/selection. Источник и гражданство жертвы не определяют
географию. Используются заголовок, первые два абзаца (до 1600 символов)
article_text или description fallback. Ищутся явные места после «в/на»;
основы стран/прилагательных и нескольких городов находятся в config.py.
Первое распознанное место заголовка имеет приоритет над началом статьи.

Это explainable rule-based распознавание, не полный географический NER:
неизвестный город без страны может остаться unknown. Unknown не считается
зарубежным, прежнее поведение сохраняется. Дополнять список следует вместе
с regression tests. Российское место в заголовке и иностранный фон в конце
не должны превращаться в зарубежное событие.

Диагностика: sexual_violence_location = foreign/domestic/unknown;
event_policy_rejection = foreign_rape; rejection_reason объясняет отсутствие
связанного убийства/группового события. Штатный DRY_RUN выводит причину отказа.
Group exception не отменяет standalone_attempt, stale_event и другие отказы.

Реальный пользовательский пример про Линчёпинг воспроизведён по присланному
тексту, без дополнительного обращения к странице: теперь отклоняется.
19 новых tests покрывают Швецию и другие страны, российские случаи,
гражданство, unknown, group, connected homicide, несвязанное убийство,
отрицание убийства, description fallback и controlled main.run.
В безопасном main.run этот материал даёт selected=0; mocks подтверждают
отсутствие Telegram, повторной загрузки HTML и save_history.
