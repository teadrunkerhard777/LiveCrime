# TrueCrime Autoposter — Roadmap

## Цель проекта

Создать полностью бесплатный автопостер для Telegram-канала, который:

- собирает криминальные новости из разных источников;
- отбирает материалы за заданный период;
- фильтрует их по нужным темам;
- удаляет дубли;
- формирует готовый пост;
- публикует его в Telegram.

Проект должен быть модульным, чтобы источники, темы, сроки и правила можно было менять без переписывания всей системы.

```python

```
