# TrueCrime Autoposter

## Стартовые требования проекта

### 1. Общий принцип

TrueCrime Autoposter — это бесплатный автопостер для Telegram-канала по тематике преступлений и криминальных новостей.

Основная задача системы:

1. Собирать новости из заданных источников.
2. Отбирать материалы за указанный период.
3. Фильтровать новости по заданным темам.
4. Удалять дубли.
5. Формировать публикацию.
6. Передавать готовый пост в Telegram.

Архитектура должна быть расширяемой, чтобы источники, темы, сроки и правила отбора можно было менять без переписывания всей программы.

---

## 2. Главное ограничение

Проект должен работать полностью бесплатно.

Не используем:

- платные AI API;
- платные новостные API;
- платные сервисы, без которых автопостер не сможет работать;
- обязательные облачные AI-сервисы.

Допускаются бесплатные библиотеки Python, открытые API, RSS, HTML-парсинг и бесплатный Telegram Bot API.

---

## 3. Источники новостей

Источники должны подключаться через конфигурацию.

Планируем поддерживать несколько типов источников:

- RSS;
- открытые бесплатные API;
- HTML-страницы новостных сайтов.

Приоритет для первой версии — RSS.

Каждый источник должен приводить полученную новость к единой структуре данных независимо от способа получения.

Пример структуры:

```python
{
    "title": "...",
    "url": "...",
    "published_at": "...",
    "description": "...",
    "source": "..."
}
```

Основное ядро автопостера не должно зависеть от того, была новость получена через RSS, API или HTML-парсинг.

---

## 4. Настраиваемые параметры

Через конфигурацию должны легко изменяться:

- список источников;
- тип источника;
- период поиска новостей;
- список интересующих тематик;
- максимальное количество материалов за один запуск;
- правила фильтрации;
- правила формирования поста.

Пример:

```python
NEWS_LOOKBACK_DAYS = 3

TOPICS = [
    "убийство",
    "покушение",
    "ограбление",
    "похищение",
    "мошенничество",
]

MAX_NEWS_PER_RUN = 5
```

---

## 5. Базовый конвейер обработки

```text
Источники
    ↓
Сбор новостей
    ↓
Приведение к единой структуре
    ↓
Фильтр по дате
    ↓
Фильтр по тематике
    ↓
Удаление дублей
    ↓
Отбор подходящих материалов
    ↓
Формирование текста поста
    ↓
Telegram
```

---

## 6. Фильтрация

На первом этапе фильтрация будет работать без AI.

Можно использовать:

- ключевые слова;
- категории;
- регулярные выражения;
- простые правила Python;
- локальные алгоритмы анализа текста.

В дальнейшем допускается использование полностью бесплатных локальных алгоритмов.

---

## 7. Дедупликация

Автопостер не должен повторно публиковать одну и ту же новость.

На первом этапе достаточно проверять:

- URL;
- заголовок;
- историю уже обработанных материалов.

Позже можно добавить определение похожих публикаций из разных источников.

Для этого можно использовать бесплатные локальные методы:

- очистку и нормализацию заголовков;
- `SequenceMatcher`;
- TF-IDF;
- cosine similarity.

---

## 8. Хранение истории

История уже обработанных и опубликованных новостей должна храниться локально.

Первая версия может использовать:

- JSON.

Позже при необходимости можно перейти на:

- SQLite.

---

## 9. Формирование публикации

На первом этапе текст поста формируется без AI.

Используем шаблон и данные исходной новости.

Пример:

```text
🔴 ЗАГОЛОВОК НОВОСТИ

Краткое описание события.

📍 Регион
📅 Дата

Источник: название СМИ
```

Формат публикации должен находиться в отдельном модуле, чтобы его можно было менять независимо от логики сбора новостей.

---

## 10. Telegram

Для публикации используется бесплатный Telegram Bot API.

Telegram подключается после того, как будут стабильно работать:

1. сбор новостей;
2. фильтрация;
3. дедупликация;
4. формирование текста.

На раннем этапе результат выводится в терминал.

---

## 11. Первая версия

### TrueCrime Autoposter v0.1

Первая рабочая версия должна:

1. Работать только на бесплатных технологиях.
2. Не использовать AI API.
3. Не использовать обязательные платные API.
4. Получать список источников из конфигурации.
5. Поддерживать RSS.
6. Приводить новости к единой структуре.
7. Отбирать новости за последние N дней.
8. Фильтровать новости по заданным темам.
9. Удалять уже обработанные материалы.
10. Ограничивать количество выбранных новостей.
11. Формировать простой текст публикации.
12. Выводить результат в терминал.

Telegram-публикация добавляется следующим этапом.

## 13. Принцип разработки

Проект строим поэтапно.

Каждый этап должен быть небольшим и законченным.

Первый технический этап:

> Научить программу получать список RSS-источников из конфигурации, собирать из них новости и приводить все материалы к единой структуре данных.

После этого последовательно добавляются фильтрация, дедупликация, генерация поста и Telegram.
